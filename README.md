# MD → HTML → PDF

Editor Markdown com preview em tempo real e exportação para PDF.

## Como usar

1. Escreva Markdown no editor (lado esquerdo)
2. Veja o preview em tempo real (lado direito)
3. Clique em "Exportar PDF" para gerar o PDF

## Desenvolvimento

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```
